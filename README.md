# Tutorial épico de Git

Proyecto sencillo creado para practicar el uso de Git y GitHub Desktop.

## Archivos

- `index.html` contiene la estructura de la página.
- `styles.css` contiene los estilos.
- `script.js` contiene una interacción sencilla con JavaScript.

## Objetivo

Usar este proyecto para practicar:

- Clone
- Fetch
- Pull
- Commit
- Push
- Crear branches
- Cambiar entre branches
